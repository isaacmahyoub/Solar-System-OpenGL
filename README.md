# 🌌 Solar System OpenGL Simulation

An advanced 3D Solar System simulation developed using **C++** and **OpenGL**, focused on delivering high-performance graphics rendering through modern graphics pipeline techniques and efficient GPU memory management.

---

## 🚀 Technical Features

### 🪐 Instanced Rendering
Utilizes `Instancing` to render the asteroid belt with thousands of instances in a single **Draw Call**, ensuring smooth real-time performance.

### ⚙️ Procedural Geometry
Planets and rings are generated programmatically inside the codebase without relying on external 3D models, making the project lightweight and highly extensible.

### 🌍 Dynamic Orbit System
A custom orbit-rendering system that accurately visualizes the orbital paths of celestial bodies around the center.

### 🎨 Shader Pipeline
A complete shader pipeline for handling:
- Lighting
- Textures
- Transformation Matrices
- Skybox rendering using `Cubemap`

### 🧩 Organized OOP Design
Built with an object-oriented architecture (OOP), making it easy to add new planets, moons, and extend physical behaviors in the future.

---

## 🛠 Prerequisites

Before running the project, make sure you have the following installed:

- **OpenGL** (version 3.3 or higher)
- **GLEW** for managing OpenGL extensions
- **GLM** for matrix and vector mathematics
- A modern **C++ compiler**, such as:
  - GCC
  - MSVC
  - Clang

## ⚙️ Installation & Running

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/isaacmahyoub/Solar-System-OpenGL.git
cd Solar-System-OpenGL
```

### 2️⃣ Project Setup

Open the project in your preferred IDE, such as:

- Visual Studio Code
- CLion
- Visual Studio

Then configure:
- Include Directories
- Linker Settings

to correctly link:
- OpenGL
- GLEW
- GLM

### 3️⃣ Build & Run

Build the project and run the generated executable.
